## What it gives you

<CardGrid>
  <Card title="Maybe instead of nil" icon="approve-check">
    Where Blizzard documents that a result can be missing, the wrapper returns a `Maybe`, and the type checker makes you
    handle the empty case.
  </Card>
  <Card title="Records instead of tuples" icon="list-format">
    Calls with several results return a read-only record named the way Blizzard names them: `info.itemLevel`, not the
    fourth of seventeen returns.
  </Card>
  <Card title="Result and Task where they fit" icon="rocket">
    Reviewed overrides turn success flags into `Result` and "not cached yet" into a `Task` that waits for the game's
    load event.
  </Card>
  <Card title="Made for the game" icon="puzzle">
    Opt-in per call, allocation-free variants for every-frame code, never a protected function, and a Lua 5.1 bundle
    tested outside the game.
  </Card>
</CardGrid>

## A taste

Hover any name to see the type Luau inferred for it. Every example on this site is type-checked against the library
and the WoW: Forever definitions when the site is built.

```luau check
local function questTitle(questID: number): string
	return Maybe.unwrapOr(Api.C_QuestLog.GetTitleForQuestID(questID), "an unknown quest")
end

local function playerPosition(): string
	local position = Api.UnitPosition("player")
	return string.format("%.1f, %.1f on map %d", position.positionX, position.positionY, position.mapID)
end

local loaded = Result.match(Api.C_AddOns.LoadAddOn("MyAddon_Data"), {
	Ok = function(_loaded: true): string
		return "loaded"
	end,
	Err = function(reason: string): string
		return "not loaded: " .. reason
	end,
})
```
